## 线路代号先认全，套餐表才看得懂

搜索“国内访问快的VPS”的人，多数是在某台机器上被晚高峰坑过一次。问题往往不在配置，而在回程路由。

**163 骨干网**是中国电信的默认国际出口，成本最低。白天勉强能用，晚上八九点国内出口拥塞，丢包率明显上升。年付几十美元的低价套餐基本都走这条。

**CN2 GT（Global Transit）**是电信 CN2 的次高档，比 163 稳一截，高峰期仍会受影响。属于“比上不足比下有余”的定位。

**CN2 GIA（AS4809，Global Internet Access）**是电信的顶级国际线路，有专用带宽保障，高峰期基本不受影响。中文 VPS 圈里“贵得有道理”的那部分溢价，大半来自这里。

**CMIN2（AS58807）**是中国移动的国际精品线路，定位对标电信 CN2 GIA，移动宽带用户走这条体验最好。

**AS9929 / CUP** 是中国联通的精品政企线路，联通侧的最优解。

**软银 SoftBank / BBTEC** 是日本机房常用线路，中日之间物理距离近，延迟天然低，价格通常比香港节点便宜不少。

## 读套餐表时，这四个数比核数重要

**回程走什么线。** 有些商家只标去程优化，回程绕路，你访问过去快、数据回来慢，实际体验照样差。页面写“回程 CN2 GIA”才算数。

**带宽上限。** 30Mbps 和 1Gbps 是两种产品。前者跑个人博客、轻量代理够用，后者才谈得上大流量分发。带宽还受月流量约束，1Gbps 端口配 1TB 月流量，等于给了你一台跑车和一小箱油。

**晚高峰的真实表现。** 国际出口在晚上拥塞是所有走国际线路的 VPS 通病，标称 1Gbps 的机器在这个时段也跑不满。判断标准是丢包率上升得缓不缓，而不是测速软件上的峰值数字。

**计费周期与续费价。** 有些商家首年给折扣、续费回到原价，有些给循环折扣、续费同价。这一步不看清，第二年账单会教你做人。

## 按使用场景定档，别为用不上的线路付钱

**个人博客、轻量代理、学习 Linux。** 三网优化不是刚需。一台年付五十美元上下、1GB 内存的普通线路机器完全够用，省下的钱可以买第二台做备份。

**建站、外贸站、面向国内用户的内容站。** 回程必须是 CN2 GIA 或同级线路。访客晚高峰打不开页面，省下的钱一分不值。这一档重点看月流量和带宽是否够你现在的访问量，别一上来就买最高配。

**移动宽带为主。** 优先找明确标注 CMIN2 的系列。同样标着“国内优化”，走电信 CN2 GIA 和走移动 CMIN2 对你是两回事。

**联通宽带为主。** 看 AS9929 / CUP 的标注。

**低延迟敏感业务，比如实时通信、游戏加速、远程桌面。** 地理距离决定下限，香港节点最近，日本次之，美国最远。愿意为这几十毫秒付费，就选香港或日本机房；不能接受这个溢价，美国节点 150ms 上下也能用。

**需要 Windows 或大内存。** 优化线路的入门档普遍只给 Linux，且内存偏小。要跑 Windows，先确认目标套餐是否支持、是否需要自备授权，再谈线路。

## 几个常被问到的问题

**国内访问快是不是等于 ping 值低？**

不完全等于。延迟 150ms 但抖动小、不丢包，实际体验比延迟 50ms 但晚高峰丢包 10% 的机器好得多。测的时候别只看 ping 的平均值，要看晚高峰时段的丢包率和延迟波动。

**CN2 GIA 和 CMIN2 哪个更适合我？**

看你用哪家宽带。电信用户选 CN2 GIA，移动用户选 CMIN2，联通用户看 AS9929。三网都覆盖的套餐最省心，价格也最高。家里是双线或者经常换网络环境的，直接选三网优化的档。

**最便宜那档能不能建站？**

能建，但要算清楚。30Mbps 带宽配 250GB 月流量，跑文字为主的博客没问题；页面带大图和视频、日访问量上千，很快就会撞到带宽和流量的墙。建站至少选 50Mbps 以上、流量 600GB 起的档位。

**买了不满意能退吗？**

DMIT 给 3 天内全额退款（流量不超过 30GB）和 30 天内部分退款，但没有理由不代表无条件：以“网络不好”为由的申请会被拒绝。所以测试要在前 3 天、30GB 流量以内做完。

**月付还是年付？**

年付单价通常比月付低一两个月，但前提是你确定这条线路对你好用。第一次买某个系列，先用月付或季付跑一个完整周期，确认晚高峰表现再转年付。反过来，如果已经用过同系列、只是换机房，直接年付省钱。
